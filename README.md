# 마음서재

감정 기반 책 큐레이션 서비스. 사용자의 현재 감정과 상황을 입력받아 책 3권(가볍게 읽을 책 / 깊이 생각할 책 / 행동을 돕는 책)과
오늘 읽을 분량, 생각할 질문을 처방한다.

**이 서비스는 의료·상담 서비스가 아니다.** 위기 표현이 감지되면 책 추천 대신 전문 상담기관을 안내한다.

---

## 로컬 실행

```bash
npm install
npm start          # http://localhost:3000
npm run dev        # 파일 변경 시 자동 재시작
```

## 배포

### 반드시 지켜야 할 것

이 앱은 `data.json` 파일 하나에 모든 데이터를 저장한다. PaaS의 기본 디스크는 **재배포·재시작 때 초기화되므로**,
반드시 영구 디스크(볼륨)를 붙이고 `DATA_DIR` 을 그 경로로 지정해야 한다. 그러지 않으면 가입 사용자와 감정 기록이 매번 사라진다.

### 환경 변수

| 변수 | 값 | 설명 |
| --- | --- | --- |
| `NODE_ENV` | `production` | `Secure` 쿠키 + `trust proxy` 활성화 |
| `DATA_DIR` | 예: `/var/data` | 영구 디스크 마운트 경로. **디스크 mountPath와 동일해야 함** |
| `PORT` | (플랫폼이 자동 주입) | 직접 설정하지 않는다 |

### Render

`render.yaml` 이 이미 들어 있다. Render 대시보드에서 **New → Blueprint** 로 저장소를 연결하면 그대로 읽는다.

- 영구 디스크는 **유료(starter) 플랜부터** 붙일 수 있다. free 플랜으로 내리면 `disk:` 블록을 지워야 배포되고, 데이터는 휘발된다.
- free 플랜은 15분간 요청이 없으면 잠들고, 다음 요청이 30초쯤 걸린다. 발표 직전에 한 번 깨워 둘 것.
- 헬스 체크: `GET /healthz` → `{ "ok": true, "books": 38 }`

### 그 외 (Fly.io / Railway)

볼륨을 만들고 `DATA_DIR` 을 마운트 경로로 지정하는 원리는 같다.

## 배포 전 알아 둘 것

| 항목 | 현재 상태 |
| --- | --- |
| 데이터베이스 | `data.json` 단일 파일. 동시 접속이 수십 명을 넘으면 교체 필요 |
| 세션 | `data.json` 에 저장. 재시작하면 전원 로그아웃(재로그인하면 됨) |
| 비밀번호 | bcrypt 해시 저장 |
| 도서 본문 | 저장하지 않음. 카드의 문장은 큐레이터가 쓴 안내 문장이며 인용이 아님 |
| 서점 연결 | 교보문고·알라딘 검색 링크 (제휴 코드 없음) |

## 구조

```
server.js        API + 추천 엔진
seed.js          감정 8종, 도서 32권, 교실용 6권, 챌린지 4개
moderation.js    위기 표현 감지 + 악플 필터 + 도배 방지
db.js            파일 기반 DB (DATA_DIR 지원)
public/          SPA (의존성 없는 바닐라 JS)
```

### 추천 엔진

`감정 일치 10점` + `보조 감정 6점` + `상황 태그 일치 × 3점` + `강도 보정`.
상황이 강하게 맞으면 보조 감정 책이 1순위를 이긴다 — "같은 불안이라도 취업 불안과 관계 불안은 다르다".
